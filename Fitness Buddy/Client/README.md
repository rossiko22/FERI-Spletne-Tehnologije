# Fitness Buddy — Client (PWA)

React 19 + TypeScript + Vite. Tailwind v4. TanStack Router (file-based).
Offline-first via IndexedDB + a service worker registered through
`vite-plugin-pwa`.

## Setup

```bash
npm install
npm run dev          # http://localhost:5173 — /api/* proxied to localhost:3000
```

For production:

```bash
npm run build        # outputs ./dist with bundled JS + CSS + service worker
npm run preview      # serve the built bundle
```

> ⚠ The school requires no external CDN links. `npm run build` produces a
> fully self-contained `dist/` — verify by grep'ing for `https://` in
> `dist/index.html` after building.

## Environment

`.env.local` (optional):

```
VITE_API_URL=http://localhost:3000/api   # default if unset; in dev a Vite proxy forwards /api → :3000
```

## Adding a new route

1. Create `src/routes/<name>.tsx`. Use the existing files as templates.
2. Export `Route = createFileRoute('/<name>')({...})`.
3. The TanStack Router plugin regenerates `routeTree.gen.ts` on save in dev.
4. Add a link in `src/routes/__root.tsx` `NAV` array if it should appear in
   the top bar.

## Style system

Tailwind v4 with CSS variables. Theme tokens live at the top of `styles.css`:

- `--primary` (#2563eb), `--background`, `--card`, `--secondary`, …
- Status: `--success`, `--warning`, `--info`, `--destructive`
- Mono font for numerals: `.stat-num`

Use Tailwind utility classes that reference these tokens (e.g.
`bg-primary text-primary-foreground`).

## Service worker

`src/sw.ts` is built by `vite-plugin-pwa` with `strategies: 'injectManifest'`.
After `npm run build` the service worker file ends up at `dist/sw.js`.

Ana implements offline caching strategies, push handler, and notification
click handling here.
